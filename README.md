# 🛠️ 維修案件全自動整理系統 (Streamlit 版)

本專案是一個專為維修案件資料整理打造的輕量化自動化 Web 系統。透過圖形化網頁介面，一鍵比對歷史案件備註、依據工作流程自動填入新進狀態，並輸出排版優化、欄位順序精確對齊的標準 Excel 總表。

---

## ✨ 核心特色與自動化功能

1. **以今日最新檔案為基準**：完整呈現今日原始檔案中的全部案件（不因歷史檔比對而遺漏）。
2. **181 個標準欄位精確對齊**：依據既定 RMA 業務規範嚴格排列所有 181 個欄位順序。
3. **TAT 排序**：自動依 `TAT_Now` 數值由小至大遞增排序，方便優先處理即將逾期案件。
4. **自動提取歷史備註**：以 `RMA_No` 為唯一鍵，自動自歷史檔案帶入 `Account`、`Status_update`、`Remark` 內容。
5. **精準狀態自動判定 (嚴格排除空白)**：
   * **Back 流程**：當 `WorkFlow` 為 `Back` 且 `Back_Receive_DT` 確實有日期內容時，若狀態為空，自動填入「`月/日已接收`」。
   * **Regular 流程**：當 `WorkFlow` 為 `Regular` 且 `Receive_DT` 確實有日期內容時，若狀態為空，自動填入「`月/日已接收`」。
   * 若對應的接收日期為空白，則狀態絕對保持空白。
6. **專業級 Excel 報表匯出**：
   * 包含微軟正黑體字型、綠色標準表頭色彩與自適應欄寬設定。
   * **缺漏預警提示**：針對未填寫品名 (`Product_Name`)、條碼 (`Barcode`) 或保固類別 (`Warranty_Type`) 的列，自動以紅色粗體醒目標示。

## 🚀 電腦安裝與快速使用指南 (SOP)

### 📌 第一次使用準備（只需做一次）

#### 步驟 1：下載並安裝 Python
本程式需要 Python 3.10+ 環境即可執行：
1. 點擊前往官方網站：[Python 官方下載點](https://www.python.org/downloads/)（建議 3.11 或 3.12 版本）。
2. **【極為重要】** 安裝程式啟動時，**請務必在最下方勾選「Add python.exe to PATH」**（將 Python 加入環境變數），然後點擊 **Install Now** 完成安裝。

#### 步驟 2：取得專案檔案
* **直接下載**：點擊 GitHub 頁面右上角綠色按鈕 `Code` ➡️ 選擇 **`Download ZIP`**，解壓縮到電腦（如桌面或磁碟機）。
* 或使用 Git 複製：
  ```bash
  git clone https://github.com/Connielll/repair-management-system.git
  ```

---

### 💻 日常使用方式（一鍵雙擊）

1. 打開本專案資料夾。
2. 雙擊滑鼠左鍵執行 **`啟動系統.bat`**。
   * **第一次啟動**：黑色視窗會自動檢查並安裝必要套件（約需 1~2 分鐘），請耐心等候。
   * **日常啟動**：約 3 秒內會自動在瀏覽器中開啟操作畫面（網址通常為 `http://localhost:8501`）。
   > 💡 **小叮嚀**：使用期間請保持黑底視窗開啟（可縮小至工具列），關閉該視窗即表示停止系統服務。

---

### 📥 系統操作三步驟

1. **左側選填上傳**：上傳前一天的「歷史總表」（包含 `Account`、`Status_update`、`Remark` 欄位）。
2. **左側必填上傳**：上傳自系統匯出的「今日原始檔案」（支援 `.xlsx` 或 `.csv`）。
3. **線上檢視與下載成果**：
   * 畫面會自動完成比對、填入新狀態，並在線上表格中即時呈現。
   * 若需手動微調，可直接在線上表格雙擊編輯儲存格內容。
   * 確認無誤後，點擊網頁下方的 **「📥 下載整理後的 Excel」** 按鈕，即可獲得完成排版的美化報表！

## ❓ 常見問題排除 (FAQ)

### Q1：點開 `啟動系統.bat` 後黑色畫面閃退，網頁沒有打開？
> **解答**：通常是因為初次安裝 Python 時漏勾了 **「Add python.exe to PATH」**。
> 請重新點開 Python 的安裝安裝程式，選擇「Modify」，將該選項補勾選後重新安裝即可。

### Q2：今天新進的案件為什麼沒有自動帶入備註？
> **解答**：新案件在歷史總表中尚無舊紀錄，因此 `Remark` 與 `Account` 呈現空白屬於正常現象；若有需要，您可以直接在網頁畫面上的表格中雙擊滑鼠補齊。

### Q3：資料會不會外洩到網路上？
> **解答**：不會。本系統完全運行在您的**本機電腦 (Localhost)**，資料處理與 Excel 產出皆在記憶體中進行，不會上傳任何第三方雲端伺服器。專案中的 `.gitignore` 也已預設排除所有 `.xlsx` 與 `.csv` 檔案，確保您的日常業務資料不會誤傳至 GitHub。
